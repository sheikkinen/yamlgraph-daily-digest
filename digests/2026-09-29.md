## [ESP32S3 cluster running 1.58-bit (BitNet) Language model](https://github.com/Low-Zi-Hong/ESP32s3-LLM-Cluster)

This project demonstrates a distributed inference system running a 0.5B language model across a 7-node ESP32-S3 cluster using 1.58-bit BitNet ternary quantization. The master node handles tokenization and embedding while worker nodes execute attention and MLP layers, communicating via high-speed SPI daisy-chain architecture.

*Why: Innovative edge AI deployment showcasing extreme model compression and distributed inference on microcontrollers. Demonstrates cutting-edge techniques for resource-constrained AI applications.*

## [How to Solve Hallucination (with RLCD)](https://www.robw.fyi/2026/09/28/how-to-solve-hallucination/)

This article examines how large language models produce confidence scores that are essentially guesses rather than genuine measurements of uncertainty. It explains the distinction between epistemic uncertainty (reducible with more data) and aleatoric uncertainty (inherent unpredictability), using weather forecasting as a concrete example to demonstrate how LLMs generate confidence statements without actual calibration mechanisms.

*Why: Addresses critical AI reliability issue with technical depth. Essential reading for understanding LLM limitations and potential solutions to hallucination problems.*
