## [Gleam doesn't compile to Erlang source anymore](https://gleam.run/news/gleam-doesnt-compile-to-erlang-source-anymore/)

Gleam v1.19.0 introduces a major change to its Erlang code generator, now outputting Erlang abstract forms (an intermediate representation) instead of Erlang source code. This architectural shift improves compiler performance, reduces build times, and provides accurate location metadata for runtime debugging. The new approach allows Gleam to skip the front-half of the Erlang compiler by directly loading binary-encoded abstract forms.

*Why: Significant compiler architecture improvement with practical performance benefits. Relevant for developers working with functional languages and compilation strategies.*
