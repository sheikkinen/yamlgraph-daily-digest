## [Turbovec – Google's TurboQuant for vector search in Rust](https://github.com/RyanCodrai/turbovec)

Turbovec is a Rust-based vector index implementation of Google Research's TurboQuant algorithm with Python bindings, designed for efficient vector search. It achieves significant memory compression while maintaining faster search performance than FAISS, with online indexing requiring no training phase.
