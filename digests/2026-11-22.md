## [Fast-Anything: Don't rewrite it in Rust. Rewrite the 5% that's slow](https://github.com/EL4CTEO/fast-anything)

fast-anything profiles Python, Node, or Ruby applications to find the few hot functions that account for most runtime. A coding agent ports only those functions to Rust, checks the ports against recorded real calls, and swaps them in, with a single command to revert. The project installs via npm or cargo.

*Why: Strong Python relevance and a useful agent-driven performance workflow with a verification step and easy rollback.*
