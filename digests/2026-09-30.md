## [Turbo Haskell](https://comonad.com/reader/2026/turbo-haskell/)

Turbo Haskell (THC) is a JIT compiler for Haskell that runs on the JVM using Truffle and GraalVM, supporting advanced features like Template Haskell and Linear Haskell. It enables both JIT and ahead-of-time compilation while providing polyglot FFI capabilities to Python, Ruby, R, and JavaScript, demonstrating the ability to compile complex Haskell programs.

*Why: Relevant for Python interoperability and polyglot development capabilities. Represents significant compiler infrastructure advancement with practical applications.*
